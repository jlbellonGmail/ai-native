# Factory Specs

This directory contains Spec-Driven Development artifacts for AI-NATIVE factory tasks and features.

Do not use this directory as a roadmap.

Roadmap and task state belong in governance.

A task or feature spec should be created only when governance confirms the task is active or when the user explicitly requests a planning artifact.

Recommended structure:

specs/<task-or-feature-id>/
├── spec.md
├── plan.md
├── tasks.md
├── verification.md
└── inspector.md

Use templates from:

.specify/templates/

Use constitution from:

.specify/memory/constitution.md
