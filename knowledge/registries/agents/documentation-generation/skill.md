# Skill: Documentation Generation

## Propósito

Generar documentación clara, estructurada y útil para desarrolladores, usuarios y agentes de IA.

## Cuándo usar esta skill

Esta habilidad debe utilizarse cuando:

* se necesita documentar una funcionalidad
* se documenta una arquitectura
* se describe un proceso o workflow
* se crea documentación técnica para un proyecto

## Proceso

1. Identificar el objetivo de la documentación.
2. Determinar la audiencia (desarrolladores, usuarios, agentes).
3. Estructurar el contenido en secciones claras.
4. Explicar conceptos de forma simple y precisa.
5. Incluir ejemplos cuando sea posible.

## Estructura recomendada

La documentación debe incluir:

* introducción o contexto
* descripción del problema o funcionalidad
* explicación de la solución
* ejemplos o casos de uso

## Resultado esperado

La aplicación de esta skill debe producir:

* documentación clara
* estructura consistente
* contenido fácil de entender
* información útil para desarrollo o uso del sistema
