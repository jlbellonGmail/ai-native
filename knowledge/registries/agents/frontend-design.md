# 🎨 Diseño Frontend

## 🎯 Propósito

Definir cómo diseñar interfaces de usuario que sean:

- Claras
- Consistentes
- Usables
- Escalables
- Alineadas con los objetivos del producto

Esta habilidad garantiza que las decisiones sobre la interfaz de usuario no sean arbitrarias, sino estructuradas y reutilizables.

--

## 🧠 Cuándo usar

Utiliza esta habilidad cuando:

- Diseñes una nueva interfaz de usuario
- Crees pantallas o flujos
- Mejores la experiencia de usuario (UX)
- Definas componentes
- Revises implementaciones frontend

---

## 🧩 Principios básicos

### 1. Claridad sobre decoración
El usuario debe entender qué hacer al instante.

### 2. Consistencia sobre creatividad
Reutiliza patrones en lugar de reinventar la interfaz de usuario.

### 3. Funcionalidad sobre estética
El diseño se centra en el caso de uso, no en la preferencia visual.

### 4. Divulgación progresiva
Muestre solo lo necesario en cada paso.

### 5. La retroalimentación es obligatoria
Cada acción del usuario debe tener una respuesta visible.

---

## 🏗️ Estructura de diseño

Toda la interfaz de usuario debe diseñarse por capas:

### 1. Diseño
Estructura y jerarquía de la página

### 2. Secciones
Agrupación lógica del contenido

### 3. Componentes
Elementos de interfaz de usuario reutilizables

### 4. Estados
Diferentes estados (cargando, vacío, error, éxito)

---

## 🧱 Reglas de diseño de componentes

- Los componentes deben ser reutilizables
- Los componentes deben tener una única responsabilidad
- Evitar componentes fuertemente acoplados
- Definir entradas/salidas claras (props)

---

## 🎯 Reglas de UX

- Minimizar el esfuerzo del usuario
- Reducir el número de pasos
- Evitar la sobrecarga cognitiva
- Utilizar patrones familiares
- Priorizar la legibilidad

---

## ⚠️ Antipatrones

Evitar:

- Pantallas sobrecargadas
- Espaciado inconsistente Tipografía
- Acciones ocultas
- Navegación poco clara
- Modales excesivos
- Reinventar componentes estándar

---

## 🔄 Proceso de diseño

Sigue esta secuencia:

1. Comprender el objetivo del usuario
2. Definir el flujo principal
3. Diseñar el diseño
4. Identificar los componentes
5. Definir los estados
6. Validar la UX
7. Implementar

---

## 🧪 Lista de verificación de validación

Antes de la implementación:

- ¿El flujo del usuario es claro?

- ¿Las acciones son obvias?

- ¿La interfaz de usuario es coherente?

- ¿Se contemplan los casos extremos?

- ¿Es reutilizable?

---

## 🧠 Reglas de uso de la IA

Al generar la interfaz de usuario:

- NO inventes diseños aleatorios.
- Sigue los patrones existentes en el proyecto.
- Reutiliza componentes siempre que sea posible.
- Respeta el sistema de diseño (si existe).

Si no existe un sistema de diseño:

→ Propón uno ANTES de implementar la interfaz de usuario.

---

## 📦 Expectativas de salida

Cuando se utilice esta habilidad, la salida debe incluir:

- Estructura de la interfaz de usuario (diseño + secciones)
- Desglose de componentes
- Flujo de interacción
- Definición de estados
- Justificación de las decisiones

---

## 📚 Referencias

Usa:

- Interfaz de usuario de proyectos existentes
- Sistemas de diseño (si están disponibles)
- Patrones de UX probados (formularios, paneles, CRUD)

---

## 🧠 Regla final

Un buen diseño no se trata de cómo se ve.

Un buen diseño se trata de la facilidad con la que el usuario logra su objetivo.
