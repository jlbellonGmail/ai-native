# Prompt Guidelines

Este documento describe buenas prácticas para diseñar prompts eficaces.

---

# Principios

Un buen prompt debe:

* definir claramente la tarea
* proporcionar contexto suficiente
* indicar el resultado esperado

---

# Estructura recomendada

Un prompt eficaz suele incluir:

1. contexto
2. tarea
3. especificaciones
4. formato de respuesta esperado

---

# Reutilización

Los prompts útiles deben guardarse para reutilización en futuros proyectos.
