# Contributing to AI Knowledge

Este repositorio contiene conocimiento reutilizable para proyectos del ecosistema AI Engineering.

---

# Cómo agregar nuevo conocimiento

Antes de agregar contenido nuevo, revisar si ya existe información similar en el repositorio.

El objetivo es evitar duplicación de conocimiento.

---

# Agregar una nueva skill

1. Crear una carpeta dentro de:

skills/

2. Nombrarla usando kebab-case.

Ejemplo:

skills/api-design

3. Crear el archivo:

skill.md

4. Registrar la nueva skill en:

skills/skills-index.md

---

# Agregar un estándar

Crear un archivo dentro de:

standards/

y registrar el estándar en:

standards/standards-index.md

---

# Principios

El conocimiento en este repositorio debe ser:

* claro
* reutilizable
* independiente de proyectos específicos
