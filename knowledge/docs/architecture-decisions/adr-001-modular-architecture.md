# ADR 001: Modular Ecosistema Global Architecture

## Status
Approved

## Context
We need to separate roles, knowledge, and execution structures across multiple projects for multi-agent collaboration.

## Decision
We enforce the tri-fold repository ecosystem:
1. `ai-knowledge` (Cerebro)
2. `ai-foundation` (Plataforma/Motor)
3. `ai-template` (Starter Enterprise)

## Consequences
- Strict decoupling.
- Standardized prompt versioning and agent skills.
