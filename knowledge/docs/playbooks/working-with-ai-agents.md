# Working with AI Agents

Este documento describe buenas prácticas para trabajar con agentes de IA en proyectos de desarrollo.

---

# Proporcionar contexto claro

Los agentes funcionan mejor cuando reciben contexto suficiente sobre:

* el objetivo de la tarea
* el proyecto
* las restricciones

---

# Reutilizar conocimiento existente

Antes de crear soluciones nuevas, los agentes deben revisar la base de conocimiento para detectar si ya existen habilidades o prácticas aplicables.

---

# Documentar decisiones

Cuando se toman decisiones importantes durante el trabajo con IA, deben documentarse para que otros agentes puedan entender el contexto.
