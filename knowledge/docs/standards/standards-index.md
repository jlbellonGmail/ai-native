# Standards Index

Este archivo proporciona un índice de los estándares definidos en la base de conocimiento.

Su objetivo es garantizar consistencia entre proyectos y facilitar que los agentes de IA sigan las mismas reglas de desarrollo.

# Uso por parte de agentes

* código
* documentación
* estructuras de proyecto

---

# Objetivo del sistema de estándares

Los estándares permiten que todos los proyectos del ecosistema compartan:

* estructura consistente
* convenciones comunes
* prácticas de desarrollo alineadas

Esto facilita la colaboración entre equipos y agentes de IA.
