# Documentation Standards

Este estándar define cómo debe escribirse la documentación técnica.

---

# Principios

La documentación debe ser:

* clara
* estructurada
* fácil de entender
* útil para desarrolladores y agentes de IA

---

# Estructura recomendada

La documentación debe incluir:

1. Introducción o contexto
2. Descripción del problema
3. Explicación de la solución
4. Ejemplos cuando sea posible

---

# Buenas prácticas

* usar títulos claros
* dividir el contenido en secciones
* evitar explicaciones ambiguas
* incluir ejemplos cuando ayuden a comprender el concepto
