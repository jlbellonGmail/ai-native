# AI Collaboration Standards

Este estándar define buenas prácticas para trabajar con agentes de IA.

---

# Principios

El trabajo con agentes de IA debe seguir estos principios:

* proporcionar contexto claro
* estructurar bien las tareas
* documentar decisiones importantes
* reutilizar conocimiento existente

---

# Buenas prácticas

Antes de generar nuevas soluciones los agentes deben:

1. consultar la base de conocimiento
2. revisar skills disponibles
3. aplicar estándares definidos

---

# Objetivo

Mantener consistencia entre proyectos y mejorar la calidad del trabajo realizado con agentes de IA.
