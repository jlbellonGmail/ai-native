# AI Development Ecosystem

Este repositorio forma parte de un ecosistema de desarrollo asistido por IA.

El ecosistema está compuesto por tres repositorios principales.

---

# 1. AI Project Foundation

Repositorio:

ai-project-foundation

Propósito:

Framework de desarrollo para proyectos asistidos por IA.

Contiene:

- roles de agentes
- workflows de desarrollo
- pipelines de entrega
- reglas de arquitectura
- prompts del sistema

Este repositorio define **cómo se desarrollan los proyectos con IA**.

---

# 2. AI Knowledge

Repositorio:

ai-knowledge

Propósito:

Base de conocimiento reutilizable para proyectos.

Contiene:

- principios de arquitectura
- estándares de desarrollo
- prácticas recomendadas
- habilidades de agentes
- guías de prompts

Este repositorio define **el conocimiento compartido entre proyectos**.

---

# 3. AI Project Template

Repositorio:

ai-project-template

Propósito:

Template base para crear proyectos reales.

Contiene:

- estructura del proyecto
- arquitectura base
- integración con agentes de IA
- base de conocimiento del proyecto

Este repositorio define **cómo iniciar nuevos proyectos**.

---

# Relación entre los repositorios

El flujo del ecosistema es:

ai-project-foundation  
↓  
define el framework de trabajo

ai-knowledge  
↓  
provee conocimiento reutilizable

ai-project-template  
↓  
permite crear proyectos reales

---

# Uso recomendado

1. Consultar **ai-project-foundation** para entender el framework.
2. Consultar **ai-knowledge** para conocimiento reusable.
3. Usar **ai-project-template** para crear nuevos proyectos.

---

# Objetivo del ecosistema

Permitir que humanos y agentes de IA colaboren eficientemente en el desarrollo de software, utilizando:

- arquitectura clara
- conocimiento estructurado
- workflows definidos
