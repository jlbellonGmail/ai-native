# Clarify

Run only when it adds value. A clear spec gets `CLEAR` and moves on; never ask artificial questions.

## Detect

Ambiguities · contradictions · implicit requirements · uncovered edge cases · missing decisions · conflicts with the constitution/contracts. Detection may be done by the Reviewer (read-only); synthesis belongs to the Planner.

## Resolve, in order

1. Evidence in the repo, existing specs or governance.
2. A documented default recorded in the spec as an assumption.
3. A question to the human — only in interactive modes or for a real block.

Remove `[NEEDS CLARIFICATION]` markers as they are resolved. Level full requires zero open markers before planning.
