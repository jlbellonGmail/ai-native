# Naming Conventions

Este estándar define convenciones de nombres para archivos, carpetas y componentes.

---

# Archivos

Los nombres de archivos deben:

* utilizar minúsculas
* separar palabras con guiones

Ejemplo:

feature-development.md

---

# Carpetas

Las carpetas deben seguir la misma convención:

architecture-design
code-review

---

# Consistencia

Es importante mantener nombres consistentes en todo el ecosistema para facilitar la navegación del repositorio.
