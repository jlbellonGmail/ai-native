# Architecture Principles

Este documento describe principios arquitectónicos utilizados en proyectos del ecosistema.

---

# Separación de conocimiento y proyecto

Los proyectos deben separar:

* lógica del proyecto
* conocimiento reutilizable

Esto permite reutilizar experiencia entre distintos sistemas.

---

# Modularidad

Los sistemas deben diseñarse utilizando componentes independientes siempre que sea posible.

Esto mejora:

* mantenibilidad
* escalabilidad
* reutilización de código

---

# Documentación de decisiones

Las decisiones arquitectónicas importantes deben documentarse para facilitar mantenimiento futuro.
