# Documentación técnica

Un archivo por feature, agregado al implementarse mediante el circuito
de agentes descrito en `AGENTS.md`: decisiones de diseño, implementación
y casos borde.

Ver también [Arquitectura](arquitectura.md) para las decisiones
estructurales del repositorio (stack, backend, dependencias de build)
que no corresponden a una sola feature.

Ver también [Circuito agentico](circuito-agentico.md) para la fuente
canónica multiherramienta, generación de adaptadores y router de modelos.

Ver también [Criterios de evaluación del repositorio](criterios-evaluacion-repo.md)
para auditar el estado acumulado del repo con checks verificables, no
una calificación subjetiva.
