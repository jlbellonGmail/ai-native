# Skill: Prompt Design

## Propósito

Diseñar prompts claros y estructurados para interactuar eficazmente con agentes de IA.

## Cuándo usar esta skill

Esta habilidad debe utilizarse cuando:

* se necesita crear un prompt reutilizable
* se quiere mejorar la calidad de respuestas de la IA
* se diseñan prompts para tareas específicas

## Proceso

1. Definir claramente el objetivo del prompt.
2. Proporcionar contexto suficiente para la tarea.
3. Especificar la tarea que debe realizar la IA.
4. Indicar criterios de calidad esperados.
5. Definir el formato deseado de la respuesta.

## Buenas prácticas

Un buen prompt debe:

* ser claro y específico
* proporcionar contexto relevante
* indicar restricciones o criterios
* definir el formato de salida esperado

## Resultado esperado

La aplicación de esta skill debe producir:

* prompts claros
* instrucciones comprensibles para la IA
* resultados consistentes
* prompts reutilizables en distintos proyectos
