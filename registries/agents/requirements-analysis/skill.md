# Skill: Requirements Analysis

## Propósito

Analizar requisitos de producto o funcionalidad para identificar objetivos, restricciones y criterios de aceptación.

## Cuándo usar esta skill

Esta habilidad debe utilizarse cuando:

* se recibe una descripción de una funcionalidad
* se necesita clarificar requisitos
* se debe estructurar una especificación

## Proceso

1. Identificar el objetivo principal de la funcionalidad.
2. Detectar actores o usuarios involucrados.
3. Determinar entradas y salidas esperadas.
4. Identificar restricciones técnicas o de negocio.
5. Definir criterios de aceptación claros.

## Resultado esperado

La aplicación de esta skill debe producir:

* descripción clara de la funcionalidad
* lista de requisitos funcionales
* criterios de aceptación
* posibles riesgos o ambigüedades
