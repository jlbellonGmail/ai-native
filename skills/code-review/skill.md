# Skill: Code Review

## Propósito

Evaluar la calidad del código para asegurar mantenibilidad, claridad y cumplimiento de estándares.

## Cuándo usar esta skill

Utilizar cuando:

* se revisa código nuevo
* se valida una implementación
* se detectan posibles mejoras

## Proceso

1. Verificar claridad y legibilidad del código.
2. Evaluar cumplimiento de estándares del proyecto.
3. Identificar posibles errores o riesgos.
4. Revisar cobertura de pruebas.
5. Proponer mejoras cuando sea necesario.

## Resultado esperado

La aplicación de esta skill debe producir:

* informe de revisión
* lista de mejoras recomendadas
* aprobación o solicitud de cambios
