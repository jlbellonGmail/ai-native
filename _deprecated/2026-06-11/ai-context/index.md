# AI Infrastructure Index

Este directorio contiene la infraestructura que permite a los agentes de IA operar dentro del proyecto.

---

# Componentes Principales

## Context

context.md

Define el contexto general del framework y el ecosistema de repositorios.

Los agentes deben leer este archivo para comprender:

- el propósito del proyecto
- el ecosistema
- las fuentes de conocimiento disponibles.

---

## Knowledge

knowledge/

Referencia a la base de conocimiento compartida del ecosistema.

El conocimiento reutilizable se mantiene en el repositorio:

ai-knowledge

Esto evita duplicación y permite que múltiples proyectos utilicen la misma base de conocimiento.

---

## Guides

Este directorio contiene guías relacionadas con el uso del framework.

Incluye:

- cómo crear nuevos proyectos
- cómo usar el template oficial
- cómo estructurar proyectos compatibles con el framework
