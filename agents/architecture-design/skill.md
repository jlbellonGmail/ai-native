# Skill: Architecture Design

## Propósito

Diseñar la arquitectura técnica necesaria para implementar una funcionalidad o sistema.

## Cuándo usar esta skill

Utilizar esta habilidad cuando:

* se debe diseñar un nuevo sistema
* se implementa una funcionalidad compleja
* se requiere definir componentes y responsabilidades

## Proceso

1. Identificar los componentes principales del sistema.
2. Definir responsabilidades de cada componente.
3. Establecer interacciones entre componentes.
4. Evaluar escalabilidad y mantenibilidad.
5. Documentar decisiones arquitectónicas.

## Resultado esperado

La aplicación de esta skill debe producir:

* descripción de componentes
* diagramas conceptuales
* decisiones arquitectónicas
* justificación técnica
