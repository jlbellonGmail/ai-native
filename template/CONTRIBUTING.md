# Contributing

Contributions must keep the template usable as a scaffold.

Before opening a change:

1. Run `node scripts/validate-enterprise-template.mjs`.
2. Run `node scripts/validate-structure.mjs`.
3. Keep generated application code under `examples/reference-app/`.
4. Keep reusable skeletons under `scaffolds/`.
5. Do not keep ambiguous legacy content in the tree: delete it and record a compact manifest under `governance/history/` if traceability is needed.
