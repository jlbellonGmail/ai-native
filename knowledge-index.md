# AI Knowledge Index

Este archivo proporciona un mapa de navegación para la base de conocimiento utilizada por los proyectos que emplean AI Project Foundation.

Su objetivo es ayudar a los agentes de IA a descubrir rápidamente qué conocimiento está disponible y dónde encontrarlo.

---

# Áreas de Conocimiento

La base de conocimiento está organizada en las siguientes áreas.

## Skills

Ubicación:

skills/

Contiene habilidades reutilizables que los agentes pueden aplicar para resolver distintos tipos de tareas.

Ejemplos:

* análisis de requisitos
* diseño de arquitectura
* generación de código
* revisión técnica

---

## Architecture

Ubicación:

architecture/

Contiene patrones y decisiones arquitectónicas utilizadas en proyectos del ecosistema.

Ejemplos:

* arquitectura modular
* separación de conocimiento y proyecto
* estructuras de repositorio

---

## Development Practices

Ubicación:

dev-practices/

Contiene buenas prácticas para el desarrollo de software.

Ejemplos:

* organización de proyectos
* prácticas de documentación
* control de versiones

---

## AI Collaboration

Ubicación:

ai-collaboration/

Contiene prácticas para trabajar de manera efectiva con agentes de IA.

Ejemplos:

* diseño de prompts
* workflows con agentes
* estrategias de colaboración humano-IA

---

## Prompts

Ubicación:

prompts/

Contiene prompts reutilizables para distintas tareas.

Ejemplos:

* generación de documentación
* análisis de código
* diseño de arquitectura

---

## Standards

Ubicación:

standards/

Define estándares técnicos utilizados en los proyectos.

Ejemplos:

* convenciones de nombres
* estructura de repositorios
* organización de documentación

---

# Uso por parte de Agentes de IA

Los agentes deben consultar este índice para:

1. identificar conocimiento reutilizable
2. localizar habilidades relevantes
3. aplicar estándares definidos

Antes de crear soluciones nuevas, los agentes deben revisar si ya existe conocimiento aplicable en esta base.
