# AI Infrastructure

La carpeta `.ai` contiene la infraestructura necesaria para trabajar con agentes de IA dentro del proyecto.

A diferencia de la documentación del proyecto, esta carpeta define componentes reutilizables para el ecosistema de desarrollo con IA.

---

# Componentes

## agents

Define configuraciones de agentes que pueden trabajar en el proyecto.

Cada agente puede tener:

* responsabilidades específicas
* prompts especializados
* reglas de comportamiento

---

## knowledge

Contiene conocimiento reutilizable entre proyectos.

Ejemplos:

* patrones de arquitectura
* convenciones de desarrollo
* guías técnicas

Este conocimiento puede sincronizarse entre distintos repositorios.

---

## templates

Define plantillas de proyectos que utilizan esta arquitectura.

Permite crear nuevos proyectos reutilizando:

* estructura
* prompts
* skills
* políticas

---

# Objetivo

Convertir el repositorio en una base reutilizable para el desarrollo asistido por IA.
