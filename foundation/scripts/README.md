# Scripts

Executable automation for `ai-foundation`.

* `ai-audit.js` runs the AI audit prompt flow.
* `validate-enterprise-10-10.mjs` validates W1/W2 product manifests.
* `validate-structure.mjs` verifies required folders, READMEs and roadmap mapping.
* `tools/` contains setup helpers moved from the former root `tools/` folder.
