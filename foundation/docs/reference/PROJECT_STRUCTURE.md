# Project Structure

Este documento describe la estructura completa del repositorio.

---

# Directorios Principales

.ai  
Contiene contexto utilizado por agentes de IA.

.ai-roles  
Define los roles de agentes que participan en el desarrollo.

.ai-workflows  
Define cómo colaboran los agentes.

.ai-pipelines  
Describe procesos completos de entrega.

.antigravity  
Define reglas de gobernanza para agentes.

prompts  
Sistema de prompts utilizados por el framework.

docs  
Sistema de documentación del proyecto.

---

# Organización de la Documentación

La documentación se divide en múltiples categorías:

explanation  
Conceptos y fundamentos del sistema.

reference  
Documentación técnica del framework.

tutorials  
Guías prácticas y ejemplos.

templates  
Plantillas reutilizables.

skills  
Documentación de habilidades utilizadas por agentes.
