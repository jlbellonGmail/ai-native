# Glossary

Este documento define términos clave utilizados dentro del framework.

---

# Agent

Entidad de inteligencia artificial que participa en el desarrollo del proyecto.

---

# Workflow

Secuencia de pasos que describe cómo colaboran los agentes.

---

# Pipeline

Proceso completo que conecta múltiples workflows hasta entregar una funcionalidad.

---

# Skill

Capacidad reutilizable que puede ser utilizada por agentes.

Las skills viven en el repositorio `ai-knowledge`.

---

# Governance

Conjunto de reglas que limitan y regulan el comportamiento de los agentes.

---

# AI-native Project

Proyecto diseñado desde el inicio para colaborar con agentes de IA.
