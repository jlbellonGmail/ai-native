# Ecosystem Overview

El framework forma parte de un ecosistema compuesto por tres repositorios principales.

ai-knowledge  
Base de conocimiento compartida.

Contiene:

- skills
- estándares
- prompts reutilizables
- prácticas de desarrollo.

---

ai-project-foundation  

Framework que define:

- estructura de proyectos
- roles de agentes
- workflows
- pipelines
- gobernanza de IA.

---

ai-project-template  

Plantilla para iniciar nuevos proyectos.

Incluye:

- estructura inicial
- integración con foundation
- configuración base.

---

Flujo del ecosistema:

ai-knowledge
      ↓
ai-project-foundation
      ↓
ai-project-template
      ↓
nuevos proyectos
