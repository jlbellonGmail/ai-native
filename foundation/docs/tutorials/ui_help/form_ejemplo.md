# Ejemplo de Ayuda de Formulario (UI)

Este documento muestra cómo debe escribirse la ayuda funcional para un formulario.

Está orientado a usuarios finales.

Este ejemplo es únicamente ilustrativo y no corresponde a una funcionalidad real del framework.

---

# Formulario: Alta de Cliente

## ¿Qué permite hacer?

Registrar un nuevo cliente dentro del sistema.

Este formulario debe utilizarse cuando se desea crear un nuevo registro de cliente.

---

## ¿Cómo se utiliza?

1. Ingresar el nombre del cliente
2. Ingresar una dirección de email válida
3. (Opcional) ingresar número de teléfono
4. Presionar **Guardar**

---

## Campos del Formulario

**Nombre**  
Nombre completo del cliente.

**Email**  
Dirección de correo electrónico del cliente.

**Teléfono**  
Número de contacto opcional.

---

## Errores Comunes

**Email inválido**  
El formato del email no es correcto.

**Campo obligatorio vacío**  
El nombre o email no fueron completados.
