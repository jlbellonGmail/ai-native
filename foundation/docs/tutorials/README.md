# Tutorials

This directory contains guided adoption material for teams using
`ai-foundation` as their runtime and operating baseline.

## Current tutorial surfaces

| Path | Purpose |
|---|---|
| `dev_help/` | Developer-facing setup and workflow guidance. |
| `ui_help/` | User-interface help material for product teams. |

Tutorial content must point to active product paths under `runtime/`, `roles/`,
`security/`, `observability/`, `config/` or `scripts/`. Historical or uncertain
material is not kept in the tree: record it in a `governance/history/` manifest.
