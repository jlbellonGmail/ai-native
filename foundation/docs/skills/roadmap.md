# Roadmap de Skills

Este documento define la evolución estratégica del sistema de **skills**
del framework **AI Project Foundation**.

Su objetivo es:

- guiar la expansión del catálogo
- priorizar capacidades estratégicas
- evitar crecimiento desordenado del sistema
- permitir que agentes y desarrolladores comprendan
  hacia dónde evoluciona el framework
- asegurar que las skills se mantengan reutilizables entre proyectos

Este roadmap define **qué capacidades tendrá el ecosistema de agentes a largo plazo**.

---

# Visión del Sistema de Skills

El sistema de skills permite extender las capacidades de los agentes mediante
conocimiento estructurado y reutilizable.

Cada skill representa una **capacidad especializada**, por ejemplo:

- diseño de interfaces
- análisis de marketing
- arquitectura de software
- investigación de producto

Las skills funcionan como **módulos de conocimiento** que los agentes pueden usar
para mejorar su capacidad de análisis, diseño y toma de decisiones.

El sistema está diseñado para ser:

- modular
- extensible
- reutilizable entre proyectos
- versionable junto con el código

# Niveles de Skills

Para evitar crecimiento desordenado, las skills se organizan por **niveles de capacidad**.

## Core Skills

Capacidades fundamentales para el funcionamiento del sistema.

Ejemplos:

- Superpowers
- AI Prompt Engineering

Estas skills afectan directamente la forma en que los agentes trabajan.

---

## Product Skills

Capacidades orientadas a entender y diseñar productos.

Ejemplos:

- Product Discovery
- UX Research

Estas skills ayudan a:

- validar ideas
- analizar necesidades de usuario
- mejorar experiencia de producto

---

## Engineering Skills

Capacidades relacionadas con arquitectura y desarrollo.

Ejemplos:

- Software Architecture Patterns
- System Design
- Code Quality Engineering

Estas skills ayudan a estructurar soluciones técnicas sólidas.

---

## Growth Skills

Capacidades orientadas a crecimiento de productos digitales.

Ejemplos:

- Marketing Skills
- Growth Engineering
- Conversion Optimization

Estas skills permiten analizar métricas, embudos y optimizar resultados.

# Estrategia Multi-Proyecto

El sistema de skills está diseñado para ser reutilizado entre múltiples proyectos.

Ejemplos de proyectos que pueden compartir este catálogo:

- AI Project Foundation
- GI Platform
- CRM especializados
- Sistemas SaaS futuros

La estrategia es mantener el **catálogo principal en la plantilla base**
y reutilizarlo en nuevos proyectos.

Esto permite:

- consistencia metodológica
- evolución controlada
- transferencia de conocimiento entre proyectos

---

# Proceso de Incorporación de una Skill

Para incorporar una nueva skill al catálogo oficial se deben completar los siguientes pasos:

1. Identificación de la capacidad necesaria
2. Selección de framework o fuente metodológica
3. Evaluación de calidad y aplicabilidad
4. Documentación de uso
5. Registro en `catalog.md`
6. Integración con agentes
7. Registro en `roadmap.md`

Solo después de completar este proceso una skill se considera **curada**.

---

# Gobernanza del Sistema de Skills

El catálogo de skills debe mantenerse bajo principios de calidad.

Reglas:

- evitar duplicación de capacidades
- priorizar frameworks consolidados
- documentar claramente cada skill
- mantener compatibilidad con el sistema de agentes

Toda modificación relevante del sistema debe reflejarse en:

- `catalog.md`
- `roadmap.md`
- `external_sources.md`

Esto asegura que el sistema evolucione de forma ordenada y sostenible.
