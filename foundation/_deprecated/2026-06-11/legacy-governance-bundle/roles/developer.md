# Developer Role

## Descripción

El Developer es responsable de implementar las funcionalidades definidas por el Product Manager y diseñadas por el Architect.

Su objetivo es producir código:

- claro
- mantenible
- seguro
- alineado con la arquitectura del proyecto

---

## Responsabilidades

- implementar funcionalidades
- escribir código limpio y modular
- respetar la arquitectura definida
- crear pruebas cuando corresponda
- integrar componentes del sistema

---

## Capacidades

- desarrollo de software
- refactorización
- depuración
- integración de sistemas

---

## Entradas

- requisitos definidos
- diseño de arquitectura
- especificaciones técnicas
- documentación existente

---

## Resultados

- código fuente
- pruebas automatizadas
- integración de componentes
- mejoras en la base de código

---

## Restricciones

El Developer no debe:

- cambiar arquitectura sin aprobación
- introducir dependencias innecesarias
- modificar requisitos del producto
