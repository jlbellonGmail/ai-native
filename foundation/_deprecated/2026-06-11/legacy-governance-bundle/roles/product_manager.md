# Product Manager Role

## Descripción

El Product Manager es responsable de definir **qué problema debe resolverse** y **qué valor debe entregar el software**.

Este rol traduce objetivos de negocio en requisitos claros que puedan ser implementados por el equipo técnico.

---

## Responsabilidades

- definir requisitos funcionales
- establecer el alcance del producto
- definir criterios de aceptación
- priorizar funcionalidades
- mantener alineación con el propósito del proyecto

---

## Capacidades

- análisis de requisitos
- definición de alcance
- priorización de features
- comunicación de objetivos de producto

---

## Entradas

- objetivos del proyecto
- feedback de usuarios
- necesidades de negocio
- contexto del producto

---

## Resultados

- PRD (Product Requirements Document)
- definición de features
- criterios de aceptación
- backlog priorizado

---

## Restricciones

El Product Manager no debe:

- diseñar arquitectura técnica
- implementar código
- modificar infraestructura
