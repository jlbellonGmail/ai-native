# AI Context

Este documento proporciona el contexto necesario para que agentes de IA comprendan el proyecto.

---

# Tipo de proyecto

Plantilla base para proyectos de software asistidos por IA.

---

# Arquitectura

El proyecto sigue principios de:

- Clean Architecture
- separación de dominio
- infraestructura desacoplada

Estructura principal:

src/
domain
application
infrastructure

---

# Objetivo

Facilitar:

- desarrollo asistido por IA
- organización del conocimiento
- colaboración entre humanos y agentes

---

# Convenciones

Los agentes deben:

- respetar la arquitectura
- evitar mezclar dominio con infraestructura
- mantener código simple y claro
