# AI Prompt Configuration

This directory contains prompt configuration material used by the template
scaffold. Prompts here are template inputs, not runtime logs and not governance
records.

## Ownership

| File | Purpose |
|---|---|
| `README.md` | Documents the prompt configuration surface for generated projects. |

Generated projects may copy this directory into their own `config/ai/prompts/`
path and then replace the sample prompt material with domain-specific prompts
that are reviewed through the knowledge registry.
