# AI Knowledge

Este repositorio contiene conocimiento compartido utilizado por proyectos que trabajan con **AI Project Foundation**.

Su objetivo es centralizar conocimiento reutilizable que pueda ser utilizado por:

* agentes de IA
* desarrolladores
* equipos de ingeniería

Esto permite reutilizar experiencia entre proyectos y mantener prácticas consistentes dentro del ecosistema.

---

# Objetivo

El repositorio actúa como una **base de conocimiento común** para proyectos de desarrollo asistido por IA.

El conocimiento almacenado aquí debe ser:

* reutilizable
* independiente de proyectos específicos
* claro y bien documentado
* útil tanto para humanos como para agentes de IA

---

# Uso en proyectos

Los proyectos basados en **AI Project Foundation** pueden utilizar este repositorio como base de conocimiento compartida.

Un proyecto típico puede utilizar esta base de conocimiento de la siguiente forma:

```
project-x
│
knowledge/
   ai-knowledge
│
.ai
.ai-agents
.ai-workflows
```

Los agentes de IA pueden consultar este conocimiento para:

* aplicar habilidades existentes
* seguir estándares definidos
* reutilizar prácticas de desarrollo
* mantener consistencia entre proyectos

---

# Evolución del conocimiento

Este repositorio está diseñado para evolucionar con el tiempo.

Nuevas habilidades, estándares o prácticas pueden agregarse cuando resulten útiles para múltiples proyectos.

Antes de agregar nuevo contenido se recomienda revisar si ya existe conocimiento similar para evitar duplicación.

---

# Ecosistema

Este repositorio forma parte de un ecosistema de desarrollo asistido por IA que incluye:

```
ai-knowledge
ai-project-foundation
ai-project-template
```

Componentes del ecosistema:

* **AI Knowledge** — base de conocimiento compartida
* **AI Project Foundation** — framework de trabajo con agentes de IA
* **AI Project Template** — plantilla para crear nuevos proyectos

Estos componentes trabajan juntos para facilitar el desarrollo de proyectos asistidos por IA.
