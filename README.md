# AI Knowledge

Este repositorio contiene conocimiento compartido entre proyectos que utilizan **AI Project Foundation**.

Su objetivo es centralizar conocimiento reutilizable para agentes de IA y equipos de desarrollo.

---

# Tipos de conocimiento

El repositorio organiza el conocimiento en varias áreas:

## Skills

Habilidades reutilizables que los agentes pueden aplicar en múltiples proyectos.

## Architecture

Patrones arquitectónicos utilizados en proyectos del ecosistema.

## Development Practices

Buenas prácticas de desarrollo y organización de proyectos.

## AI Collaboration

Prácticas para trabajar eficazmente con agentes de IA.

## Prompts

Prompts reutilizables para distintos tipos de tareas.

## Standards

Estándares técnicos utilizados en los proyectos del ecosistema.

---

# Relación con AI Project Foundation

Los proyectos creados con **AI Project Foundation** pueden utilizar este repositorio como base de conocimiento compartida.

Esto permite:

* reutilizar experiencia entre proyectos
* mejorar prácticas de desarrollo
* evolucionar el ecosistema de forma consistente.
