## Cambios de comportamiento

1. **`/sdd-validate`** pasa de `role: reviewer`, `readOnly: true` a `role: coordinator`, `readOnly: false`, `writes: review-state` (`contracts/sdd-workflow.json`): ejecuta la validación técnica, delega la review al Reviewer cuando el runtime puede aislarla (si no, self-review) y solo escribe el estado de review (ledger `specs/<slug>/reviews.jsonl` y estado de la plataforma en el git dir, vía `sdd review`). No modifica código.
2. **Codex y OpenCode**, que no pueden demostrar una review independiente, reportan:

   ```text
   SELF_REVIEW: PASS
   INDEPENDENT_REVIEW: UNAVAILABLE
   FINAL_REVIEW_STATUS: REVIEW_PENDING
   HUMAN_GATE: required
   ```

3. **Claude Code** solo produce `INDEPENDENT_REVIEW: PASS` con evidencia runtime-attested válida: recibo del hook `SubagentStop` (`matcher: reviewer`) verificado contra el transcript del runtime, con nonce, revisión y prompt de delegación coincidentes, y una delegación sin `model` distinto del proyectado para el Reviewer (`core/agents.json`) ni `isolation`. Sin esa evidencia el resultado es `NOT_PROVEN`/`REVIEW_PENDING`, nunca un PASS falso.
