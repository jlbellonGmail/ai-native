# v3.3.0 — actualizaciones de dependencias (GitHub Actions) revisadas antes del release

Estado: incorporadas en la PR de cierre de v3.3.0 (no hay tag ni release). Revisión del 2026-10-14 contra las PR abiertas de Dependabot (#117–#121).

Criterio: entran las actualizaciones patch o minor de acciones ya usadas, fijadas por SHA completo (validador `scripts/validate-actions-pinned.mjs`), sin cambio de contrato público ni migración y con notas de la release de origen que no declaren cambios incompatibles. Se comprobó, con `gh api`, que cada SHA es exactamente el commit del tag indicado.

|---|---|---|---|---|---|
| #117 | `actions/download-artifact` | v8.0.1 | v8.0.2 | patch | reintentos ante HTTP 429 y `@actions/artifact` 6.3.1 |

| #121 | `actions/upload-artifact` | v7.0.1 | v7.0.2 | patch | reintentos ante HTTP 429 y `@actions/artifact` 6.3.1 |

Las cinco PR de Dependabot fallaban `pr-gate` (`DOCS_NOT_UPDATED`) y, por arrastre, `security-scan` y `merge-gate`: cambian ficheros de `.github/**` sin tocar documentación. Se reaplican aquí con los mismos diffs exactos y este documento. Al fusionarse esta PR, Dependabot cierra las suyas por obsoletas; si no lo hace, se cierran a mano.

Excluidas: ninguna. No hay majors, ni dependencias de ejecución (el repositorio no instala paquetes: solo módulos `node:*`).

Los workflows `release.yml`, `codeql.yml`, `ci.yml`, `l3-consumer.yml` y `sbom.yml` son plano de control (`governance/gates/gates.json`): esta PR requiere la aprobación humana del Environment `ai-native-human-review` y el merge lo hace una persona (`governance/security/HITL-MERGE-POLICY.md`).
