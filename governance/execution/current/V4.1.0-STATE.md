## CI incident resolved in this candidate

Ubuntu `validators` jobs 139214303018 (`83f0de6`) and 139242153894 (`ebe9850`) ended with "The hosted runner lost
communication with the server" during the `runtime/acceptance` step, with no log uploaded. Cause: a runner test fakes
a child with pid 1, and the post-exit process-group kill added in `66a3e0c` became `kill(-1, SIGKILL)` on Linux,
which signals every process of the user, including the runner agent. Fixed in `a70e6bd` (`groupKillTarget`: only
an integer pid > 1 becomes a group target), with regression tests; CI run 45650505206 green on both OSes.

Final code head `59369df`: CI run 45676272070 green (Ubuntu 4m42s, Windows 16m24s; `runtime/circuit` on Windows
6m43s). Locally `runtime/circuit/review-ledger.test.mjs` exceeded 25 and 45 minute caps twice while the host was
loaded by another process; it was shown to be progressing (new child commands every few seconds), not hung, and
is covered by that CI run. Last complete local pass of it: 60/62, 0 fail, 2 skipped (before `7d9e2b7`).
