## Design decision for the human (deviation from the approved 002 plan)

The 002 plan designed a new `acceptance-governance.yml` holding the `ai-native-trust` App key. Per the instruction
to minimize key holders, the candidate instead runs the analysis in a secret-free job of the existing
`merge-gate.yml` and publishes through its existing holders (exactly two holder workflows, enforced by
`secret-exposure.test.mjs`). Consequence: the trusted verdict exists only for PRs to `main` (where merge-gate runs);
for `develop` RF-25 is BLOCKED until the human decides to run the gate there as well. The plan text
(`specs/002-native-acceptance/plan.md`) is unchanged and needs the human's acceptance of this deviation.
