# H5 - Real Evaluation Runs

H5 closes a local controlled real evaluation execution path for
`AI-NATIVE HARDENING-V1.1`.

Scope:

* add a local evaluation runner in `ai-knowledge`
* run `bench-prompt-grounding` against controlled fixture data
* produce a machine-readable score report
* validate the report against benchmarks, datasets, scoring and quality gates
* document evidence policy for evaluation runs
* close H5 locally in governance

Non-goals:

* H6 Target Repository Security Validation
* H7 First Client Project Playbook
* H8 Adoption Readiness Final Audit
* external model calls, remote CI, push or PR
* modifying `ai-template/templates/project/`
* reopening H1, H2, H3 or H4
* reopening `ENTERPRISE-10-10-V1`
* creating `ENTERPRISE-10-10-V2`
